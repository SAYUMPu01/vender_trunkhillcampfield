# Trunkhill Campfield

ระบบจองลาน ห้องพัก และเช่าอุปกรณ์ด้วย Next.js และ MySQL/MariaDB

## เปิดบนเครื่อง

ต้องมี Node.js 22 ขึ้นไป, npm และ Docker Desktop

```powershell
npm ci
docker run --detach --name trunkhill-local-db --publish 127.0.0.1:33316:3306 --env MARIADB_RANDOM_ROOT_PASSWORD=1 --env MARIADB_DATABASE=trunkhill --env MARIADB_USER=trunkhill --env MARIADB_PASSWORD=local-trunkhill-db mariadb:11.4
Copy-Item .env.example .env.local
```

ถ้าคอนเทนเนอร์มีอยู่แล้วแต่หยุดอยู่ ใช้ `docker start trunkhill-local-db` แก้ `.env.local` ให้มี `ADMIN_PASSWORD` อย่างน้อย 12 ตัวอักษรและ `ADMIN_SESSION_SECRET` แบบสุ่มอย่างน้อย 32 ตัวอักษร ตัวอย่างคำสั่งสร้าง secret คือ `node -e "console.log(require('node:crypto').randomBytes(40).toString('hex'))"`

```powershell
npm run db:init
npm run dev -- --hostname 127.0.0.1
```

เปิด http://127.0.0.1:3000 และเข้าหน้าจัดการที่ http://127.0.0.1:3000/admin โดยใช้รหัสใน `.env.local`

ฐานข้อมูลเดิมให้รัน `npm run db:init -- --reschedule-only` ก่อนเปิดเว็บที่มีระบบเลื่อนวันเข้าพัก

## Check-out ในแอดมิน

ฐานข้อมูลเดิมให้รัน `npm run db:init -- --checkout-only` ก่อนเปิดเว็บเวอร์ชันนี้

1. ไปที่ **ตั้งค่า Check-out** เพื่อปรับหน่วยไฟฟรีต่อคน ค่าไฟต่อหน่วย และเลขพร้อมเพย์ของแคมป์ ค่าเริ่มต้นคือ 1 หน่วยฟรีต่อคนและ 10 บาทต่อหน่วย
2. ในเมนู **Check-out** เปิดรายการจองที่ยืนยันแล้ว กรอกจำนวนหน่วยไฟ ค่าของชำรุด หรือค่าใช้จ่ายอื่น ๆ แล้วบันทึกยอด
3. ให้ลูกค้าสแกน QR สำหรับยอดที่ต้องชำระเพิ่ม เมื่อแอดมินตรวจสอบว่าได้รับเงินแล้วจึงกดยืนยัน Check-out

ระบบหักหน่วยฟรี (หน่วยฟรีต่อคน × ผู้เข้าพักทั้งหมด ÷ จำนวนล็อก) ก่อนคิดค่าไฟ และคิดเฉพาะหน่วยส่วนเกิน รายการที่ไม่มีล็อกใช้ตัวหาร 1 รายการที่บันทึกอัตราค่าไฟแล้วใช้สูตรที่บันทึกไว้กับรายการนั้น

## การจองและข้อมูลเริ่มต้น

- Zone A มี A01–A10 ตามแบบ ราคาเริ่มต้น 150 บาทต่อคนต่อคืน หรือ 500 บาทต่อล็อกต่อคืนตามโหมดที่แอดมินเลือก การคิดตามคนใช้เกณฑ์เด็กอายุไม่เกิน 13 ปีและผู้สูงอายุ 65 ปีขึ้นไปเข้าพักฟรี และคิดขั้นต่ำ 2 คนต่อล็อกเมื่อจองหลายล็อก
- ราคาเช่า Snow Peak 600 บาทต่อคืน จำนวน 3 ชิ้นเป็นตัวอย่าง โซน B–D และ Trunkbox ยังไม่มีรายการเริ่มต้น แอดมินเพิ่มรายการ ตั้งราคา แก้สต็อก และเปิดหรือปิดรับจองได้
- เมื่อส่งคำขอ ระบบกันลานและสต็อกทันทีและขึ้นสถานะรอตรวจสอบ แอดมินยืนยันหรือยกเลิกได้ การยกเลิกคืนสต็อกทันที ผู้จองใช้รหัสและเบอร์โทรตรวจสถานะที่ `/booking` รายการที่ยืนยันแล้วเลื่อนได้ไม่เกิน 3 ครั้ง โดยเลื่อนล่วงหน้าอย่างน้อย 3 วันก่อนวันเข้าพักเดิมและคงจำนวนคืน ล็อก และอุปกรณ์เดิมไว้
- รุ่นนี้ใช้การยืนยันโดยแอดมิน และยังไม่เชื่อมระบบรับชำระเงินออนไลน์

## ทดสอบโหลดบนเครื่อง

เปิด production build ด้วย `npm run build -- --webpack` และ `npm start -- --hostname 127.0.0.1` จากนั้นเปิดอีกเทอร์มินัลแล้วรัน

```powershell
node --env-file=.env.local scripts/load-local.mjs
```

สคริปต์ทดสอบ 1,000 คำขอเช็กว่างพร้อมกัน และสองชุดอย่างละ 200 คำขอที่แข่งกันจองล็อกเดียวหรือเช่าอุปกรณ์ที่มีสามชิ้น รวมถึงการส่งซ้ำด้วยรหัสคำขอเดิม สคริปต์ใช้รายการชั่วคราวในฐานข้อมูลทดสอบแล้วล้างเฉพาะข้อมูลของรอบนั้น

ระบบใช้ InnoDB และล็อกแต่ละรายการตามลำดับรหัสระหว่างตรวจสต็อกและเขียนการจอง ราคาเก็บ ณ เวลาจอง สต็อกแยกตามคืนและไม่นับคืนวันเช็กเอาต์ การทดสอบบนเครื่องไม่ใช่ค่ารับประกันสำหรับ shared hosting

ก่อนเปิดใช้งานจริง ให้ตั้งฐานข้อมูลจริงและค่าลับผ่าน environment ของ Plesk ตั้ง cookie เป็น HTTPS เปลี่ยนรหัสแอดมินและ secret ตรวจข้อมูลจริงของทุกโซน และตั้งการจำกัดอัตราคำขอสำหรับการจองและการเข้าสู่ระบบ จากนั้นทดสอบโหลดบนสภาพแวดล้อมปลายทางและตรวจเวลาตอบสนอง การจำกัด CPU/RAM และจำนวน connection ของฐานข้อมูล
